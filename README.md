Excel Project Dashboard Analysis

This dashboard provides a comprehensive overview of an online store's performance. It presents key metrics and visualizations to help analyze various aspects of the business.

Key Metrics:

Total Customers: Displays the total number of customers associated with the online store.
Average Days for Product: Indicates the average time taken for a product to become available for sale.
Top 5 State of Customer: Shows the top 5 states from where the most customers originate.
Average Days for Pet Shop: Reveals the average time taken for pet shop-related products to be sold.
Relationship Between Shipping Days and Review Score: Analyzes the correlation between shipping days and customer review scores.
Total No of Order With Payment Type: Displays the number of orders placed using different payment methods.
Top 5 Sales Product: Highlights the top 5 best-selling products.
Charts and Visualizations:

Pie Charts: Used to represent the proportion of data across different categories. For example, the distribution of orders based on payment types.
Bar Charts: Employed to compare data across various categories. For instance, the number of customers from the top 5 states.
Line Charts: Utilized to analyze how data changes over time. For example, daily/weekly/monthly sales trends.
Uses of the Dashboard:

Measuring Business Performance: The dashboard helps in assessing the overall performance of the online store.
Identifying Areas for Improvement: By analyzing the data, it becomes possible to pinpoint weaknesses in the business and implement corrective measures.
Decision Making: The insights gained from the dashboard can aid in making informed decisions, such as launching new products or devising effective marketing strategies.
Additional Information:

Data Source: The source from which the dashboard retrieves data (e.g., Excel sheet, database).
Calculations: The calculations used within the dashboard.
Filters: Available filters to refine the data analysis (e.g., date, product category).
